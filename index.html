L4 · machine learning

Character-Level Transformer LM

A decoder-only transformer built from scratch in PyTorch — causal self-attention, pre-norm LayerNorm, GELU, and learned positional embeddings — trained on the CPython standard library to generate Python character by character. The attention math is hand-written; a unit test proves the causal mask.

PyTorchSelf-attention 3.3M params4 layers · 4 heads
0.93 nats/char val loss on the 11 MB CPython stdlib · RTX 5080 · results and samples in the repo
L4 · reinforcement learning

chess-rl

An AlphaZero-style chess agent: PUCT Monte Carlo Tree Search guided by a residual policy/value network, parallel self-play workers, a live board to watch it train. Measured honestly against a random baseline — the README says what it reaches and what it doesn't.

MCTSSelf-play PyTorch2.4M params
python-chess · 17×8×8 state planes · 4096-move policy · seeded runs and ablations
L2 · systems

mini-os32

A 32-bit x86 operating system in C — BIOS and UEFI boot, kernel, NVMe driver, filesystem, framebuffer console, shell — with its own in-OS C compiler (cc) that is self-hosting: it compiles its own source inside the OS, and the result compiles it again to a byte-identical binary.

Cx86 Assembly Self-hosting compilerUEFIQEMU
13.9K lines · 44 syscalls · 51-program compiler test-suite · boot → kernel → syscalls → fs → shell → cc
L0 · hardware

custom-16bit-CPU

A 16-bit RISC CPU designed gate by gate from a single NAND — 5,004 of them — with an assembler, programs verified on the Verilog export under Icarus, and a completed OpenLane / sky130 layout run (DRC and LVS clean). The foundation everything above stands on.

Digital logicVerilog YosysOpenLane / sky130
16 opcodes · 20K transistors of hand-built logic · 1.07 mm² sky130 layout
